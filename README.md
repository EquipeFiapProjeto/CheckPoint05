# 🛍️ Catálogo de Produtos

Projeto desenvolvido com **Next.js 13+**, **TypeScript** e **Axios** para exibir um catálogo de produtos a partir da API pública [DummyJSON](https://dummyjson.com/products).

## 🚀 Funcionalidades

- ✅ Listagem de produtos com exibição em cards
- ✅ Página de detalhes para cada produto
- ✅ Estilização com CSS Modules
- ✅ Consumo de API com Axios
- ✅ Código com boas práticas e comentários

## 🔧 Tecnologias Utilizadas

- [Next.js](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Axios](https://axios-http.com/)
- [CSS Modules](https://nextjs.org/docs/basic-features/built-in-css-support#adding-component-level-css)
